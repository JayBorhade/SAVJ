# Phase 14 — Worker directory

## Delivered
- Add an authenticated worker directory API for accounts that are enabled for worker work (Worker or Both).
- Search by display name/locality and filter by self-declared skills.
- Return only public profile fields; email addresses and password data are never included in worker directory responses.
- Add frontend directory navigation, search, skill filters, and links back to task discovery.
- Add backend tests for search, skills and email-field privacy.

## Not claimed
Worker listings show member-provided skills only. Identity/KYC verification, ratings, reviews, background checks and contact details are not represented as verified because those workflows are not yet implemented.
